# 🔐 Credit Card Fraud Detection — ML Web Application

A Machine Learning web application that detects fraudulent credit card transactions
using the **Credit Card Fraud 2026** dataset (20 000 transactions, 25 features).

## 📊 Dataset
- **File:** `data/dataset.csv`
- **Rows:** 20 000
- **Target:** `is_fraud` (0 = Legitimate, 1 = Fraud)
- **Task:** Binary Classification

## 🧠 ML Pipeline
- Data preprocessing: `StandardScaler` for numerics, `OneHotEncoder` for categoricals
- Models compared: Logistic Regression, Random Forest, Gradient Boosting
- Best model selected by 5-fold cross-validated F1-macro score
- Pipeline serialised to `models/model.pkl` using `joblib`

## 🚀 Local Setup & Run

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Create & activate a virtual environment (recommended)
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the model
```bash
python train_model.py
```
This will create `models/model.pkl`.

### 5. Launch the Streamlit app
```bash
streamlit run app.py
```
Open [http://localhost:8501](http://localhost:8501) in your browser.

## ☁️ Deploy to Streamlit Community Cloud

1. Push the repository to GitHub (include `data/dataset.csv` and `requirements.txt`).
2. Go to [https://streamlit.io/cloud](https://streamlit.io/cloud) and sign in.
3. Click **New app** → select your repository and `app.py` as the entry point.
4. In **Advanced settings → Secrets**, add any environment variables if needed.
5. **Important:** run `python train_model.py` locally first and commit `models/model.pkl`
   to the repository, **or** add a `@st.cache_resource` step that trains on first start
   (already handled in `app.py` — it shows an error if the model is missing and
   instructs the user to train first).

> **Tip for Streamlit Cloud:** Commit `models/model.pkl` to the repo so the app
> starts immediately without a separate training step.
